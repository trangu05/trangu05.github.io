# Tra Nguyen Academic Website

This is a static academic website prepared for GitHub Pages.

## Publish with GitHub Pages

1. Create a public GitHub repository named `trangu05.github.io`, or use an existing repository.
2. Upload `index.html`, `styles.css`, `.nojekyll`, and the `assets/` folder to the repository.
3. In GitHub, open Settings, then Pages.
4. Set the source to the `main` branch and the root folder.
5. Wait for GitHub Pages to publish the site.

The site is configured for the custom domain `tranguyenecon.com`.
